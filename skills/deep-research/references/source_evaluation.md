# Source Evaluation & Verification Criteria

## Credibility Checklist
1. **Primary vs Secondary**: Prioritize official vendor documentation, RFCs, peer-reviewed benchmarks, and official source code over speculative blog posts.
2. **Temporal Validity**: Check release notes and API versions to ensure guidance matches current major version releases.
3. **Reproducibility**: Ensure cited metrics (e.g. latency, throughput) include hardware context and workload profiles.
